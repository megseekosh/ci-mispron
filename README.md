# ci-mispron

Code to replicate results from:

Cychosz, M., Mahr, T., Munson, B., Newman, R., & Edwards, J. R. (2023). Preschoolers rely on rich speech representations to process variable speech. *Child Development 94,*(4), e197-e214. [10.31234/osf.io/cj8qp](https://psyarxiv.com/cj8qp/)


# datasets

* `model.csv.gz` - contains props of looks to target for all children

* `scores.csv` - contains scores for standardized assessments 

* `audio_info.csv` - contains audiological information for children with cochlear implants

* `hearing_age.csv` - contains hearing ages for all participants

* `audiological_info.csv` - generated by `1_audiological_information.R`

# modeling and scripts to replicate results

* `0_match_children.Rmd` - match children with cochlear implants to children with typical hearing by vocabulary size and hearing age

* `1_audiological_information.R` - organize etiological information for children with cochlear implants

* `2_modeling.Rmd` - replicate the results section of the manuscript
  
# extra scripts

* `99_elogit_demo.Rmd` - verify that we don't need to weight observations within the GAMMs

* `create_dark_tables.R` - a function to render darker in-line Kable tables when using a dark RStudio theme

Note: the looking proportions in Results (0.22 for the CI group, 0.33 for the TH group) came from a plogis() call where a rounding digit was passed as the location parameter, computing plogis(est − 2) instead of plogis(est). The correct back-transformed values are 0.68 and 0.79. No model estimate, table, or figure is affected.

Note (Oct 2026): models in the paper were fit with mgcv 1.8-38 (R 4.0.2). Newer mgcv software versions reproduce all coefficients and conclusions, but the estimated smooths for two terms (the near-zero s(Time) in Table 4 and the binary-model difference smooth, p = .004 originally vs p = .04 on current versions) differ numerically; exact replication requires the original mgcv 1.8-38 (R 4.0.2).
